awesome-anime-prompt-as-code

面向 GPT-Image-2 及通用图像模型的动漫提示词结构化模板库。
把角色、画风、材质、光影、镜头、环境和叙事，拆成可复用、可校验、可跨平台调用的 Prompt 协议。

49 YAML 模板 40+ 风格锚点 9 分层词库 2 JSON Schema MIT License
主体 + L1 基础体系 + L2 流派/时代 + L3 渲染质感
+ L4 光影 + L5 镜头 + L6 环境 + L7 情绪

🎨 动漫视觉语言库

日漫经典、国漫（仙侠/水墨/工笔）、手绘水彩、游戏立绘、赛博机甲恐怖末日、欧美动画——每风格一个 YAML 模板。

🎬 镜头与叙事库

角色首帧、小说封面、短剧分镜、双人对峙、情绪特写、建立镜头。光影/镜头/环境/情绪四维词库独立检索。

👥 多角色同框控制

不撞脸三板斧：发型对比 × 轮廓对比 × 站位声明。审讯室对峙、雨夜对决、主角团出场三大模板。

🔁 角色一致性协议

Character Bible 冻结外貌/服装/标志道具锚点，先定妆后量产，跨场景不漂移。

🔌 模型适配层

同一份 YAML 自动适配 GPT-Image-2（无负向字段→指令改写）、Midjourney niji 6、Flux、SDXL、即梦、可灵。
